# Creative Radaar Chrome Collector 1.3.0

البحث والجمع الأساسيان يعملان من تبويب Chrome ظاهر، وليس عبر fetch لصفحات أمازون. عند الضغط على البحث، تنشئ الإضافة تبويب عمل واحدًا وتتنقل فيه بين روابط البحث والمنتجات المحددة؛ لا تفتح نوافذ مخفية ولا تستخدم Proxy أو تغيير هوية المتصفح. Chrome يستخدم جلسته العادية؛ الإضافة لا تقرأ أو تنقل الكوكيز أو كلمات السر أو بيانات الحساب.

القراءة من أقسام المنتجات والريفيوهات العامة فقط. لا تنقل الصفحة الكاملة أو حقول النماذج. يتم التحقق من رابط المصدر، query/page أو ASIN، وjobId قبل قبول كل نتيجة. البحث الجديد والإلغاء يوقفان انتظار العمل القديم؛ الرد المتأخر لا يدخل في البحث الجديد. إغلاق تبويب العمل يوقف العملية ولا يُعاد فتحه تلقائيًا داخل نفس البحث.

لا يوجد fetch تلقائي بديل بعد فشل التبويب. إذا ظهر تحقق أو تسجيل دخول أو رفض من أمازون، يتوقف البحث ويترك الصفحة للمستخدم. أمر استكمال التحقق يفحص الصفحة الحالية فقط دون إعادة تحميل أو نقر. صلاحيات المضيف كما هي: Amazon.com وAmazon.eg وAmazon.sa وAmazon.ae؛ لا cookies/tabs/storage/scripting permissions جديدة. البيانات تبقى مؤقتة داخل المتصفح، دون تخزين ميديا.

يمكن إدخال اسم المنتج أو رابط Amazon مباشر أو ASIN في حقل واحد. الرابط/ASIN يجلب ريفيوهات نفس الرقم فقط. البحث بالاسم لا يضمن الموديل، ومطابقة الصور لا تثبت رقم موديل غير ظاهر أو تضمن وجود المنتج في السوق المحدد. الأعداد سقف حسب المتاح وليست ضمانًا.

الإصدار يحتاج تثبيت 1.3.0 وتعطيل النسخ القديمة لتجنب طلبات متكررة. بعد Load unpacked أعد تحميل الموقع وصفحات Amazon. الحزمة تُبنى بواسطة npm run build:extension. لا تُثبّت أو تُفعّل الإضافة آليًا. المصدر الرئيسي: Chrome Tabs API وMessaging API الرسمية.
