# جلب مجاني من متصفح المستخدم

هذه إضافة Manifest V3 بدون خدمة مدفوعة أو مفتاح API. المصدر هو صفحات أمازون العامة عبر اتصال كل مستخدم. تثبيت مرة واحدة على Chrome/Edge للكمبيوتر، ثم إعادة تحميل Creative Radaar. راجع `public/extension-install.html` للتعليمات.

الإصدار 1.2.2. الصلاحيات ما زالت محددة بأربعة متاجر أمازون؛ لا cookies أو tabs أو storage permissions جديدة. جلب الشبكة يستخدم `credentials: omit` و`redirect: error`، ويتوقف عند 403/429/503 مع مهلة لا تقل عن دقيقة ويحترم Retry-After. لا إعادة محاولة تلقائية ولا تغيير متجر للتحايل على الرفض.

مسار بديل يدوي: يفتح المستخدم صفحة منتج بنفسه في Chrome ويختارها صراحةً من الموقع. القارئ الجديد على أمازون يعيد عنوان المنتج وASIN وصور/بيانات مراجعات العملاء المسموحة فقط، ولا يرسل الصفحة الكاملة أو بيانات الحساب أو حقول النماذج أو الكوكيز. يرفض صفحات التحقق والدخول والموديل المختلف. لا يفتح تبويبات ولا ينقلها أو ينقر أي تحقق. القراءة من DOM ظاهر ومحمل مسبقًا؛ لا طلب fetch جديد لأمازون. الاختيار يدوي ولا يدعي مطابقة الصورة آليًا. قد يلزم فتح قسم مراجعات العملاء والفيديوهات لتحميلها.

حدود الجلب الآلي 25 ثانية/8MB؛ حد لقطة الصفحة اليدوية 4MB. التبويبات المعروضة تقتصر على روابط منتجات متاجر أمازون الأربعة. نقل المحتوى إلى واجهة الموقع داخل المتصفح فقط، دون تخزين دائم. بعد تحديث الإضافة، اضغط Reload عليها ثم أعد تحميل صفحة أمازون والموقع مرة واحدة لتفعيل القارئ الجديد.


المستخدم يختار فيديوهات أو صورًا أو الاثنين، وعددًا مستقلًا من 1 إلى 50. البحث يفحص حتى 5 صفحات (20 منتجًا في الصفحة)، مرتبة داخل كل دفعة بعدد التقييمات، ويتوقف عند بلوغ العدد المطلوب أو نفاد النطاق أو الحظر. العدادات تفصل عدد النتائج عن عدد المنتجات المفحوصة. الصور مأخوذة فقط من حاويات مراجعات العملاء وليست صور البائع. الفيديوهات تشترط دليل customer ومطابقة ASIN. الرقم سقف وليس ضمانًا. الحظر والتحقق البشري قد يحدثان أيضًا على اتصال المستخدم. لا يتم حلهما تلقائيًا. بيانات HTML ترجع للواجهة المحلية داخل المتصفح فقط؛ خدمة Railway الحالية تظل مسؤولة عن أكواد الدخول وبث الوسائط عند التشغيل والتنزيل. رابط تنزيل الإضافة يختفي بعد تأكيد الاتصال بها، دون الاعتماد على علامة مخزنة قديمة.

حزمة ZIP تُبنى قبل نشر الواجهة بواسطة `npm run build:extension`. لا يتم تثبيت الإضافة أو منحها صلاحيات تلقائيًا. لم تُنشر في Chrome Web Store لأن حساب النشر له متطلبات منفصلة.
