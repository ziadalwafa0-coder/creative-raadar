# Creative Radaar — إضافة Chrome 1.3.2

الجلب الأساسي يستخدم تبويب أمازون واحدًا ظاهرًا في Chrome ويعيد استخدامه للبحث وصفحات المنتجات. لا يستخدم طلبات HTML مباشرة ولا بروكسي أو تبديل هوية الطلب. إذا ظهرت صفحة تحقق أو تسجيل دخول أو رفض، يتوقف ولا ينتقل لصفحات أخرى تلقائيًا. يمكنك مراجعة التبويب بنفسك ثم طلب فحصه من خيارات الاستكمال.

الموقع يجمع ريفيوهات العملاء فقط، ويعرض النتائج بالتتابع حتى العدد المحدد أو نفاد النتائج. العدد غير مضمون لكل منتج. تغيير المنتج أو تحديث الصفحة يمسح النتائج، والتنزيل يبدأ عند الطلب؛ لا يتم حفظ الفيديوهات في التطبيق.

الصورة تلميح اختياري للبحث ولا تؤكد الموديل وحدها. تحليلها يستخدم مقارنة محلية؛ تحسين عبارات البحث عبر Gemini اختياري على السيرفر بمفتاح غير مضمّن في الإضافة. قد تُرسل صورة مصغرة حتى 320 بكسل إلى السيرفر وGemini عند تفعيله، ولا يخزنها التطبيق.

للتثبيت: عطّل الإصدارات القديمة، افتح chrome://extensions، ثم Load unpacked واختر الفولدر المحتوي على manifest.json. تأكد أن نسخة 1.3.2 وحدها مفعّلة، ثم حدّث الموقع. نفس صلاحيات المتاجر الحالية، دون قراءة الحساب أو كلمات السر أو الكوكيز.
