# Creative Radaar 1.3.1

اكتب اسم المنتج بالعربي وأضف صورته اختياريًا، واختر صور العملاء أو الفيديوهات أو الاثنين وعدد كل نوع. الصورة تساعد ولا توقف البحث إذا لم تتطابق. إذا لم يُؤكد الموديل تُعرض رسالة واضحة؛ الرابط المباشر يقيّد النتائج بنفس ASIN.

الجلب الأساسي طلبات HTTP عامة من الإضافة، بدون إنشاء تبويب أو نافذة، وبلا كوكيز الحساب أو تغيير الهوية أو البروكسي. رفض أمازون أو التحقق يوقف البحث دون محاولة النقل عبر تبويب. هذا المسار لا يستطيع تشغيل محتوى أمازون الكسول وقد يرجع 503؛ لا يوجد ضمان لتوفر الميديا.

قارئ الصفحات المفتوحة يدويًا اختيار إضافي منفصل. يمرر قسم الريفيوهات للعرض ثم يفتح زر الفيديوهات داخل نفس القسم عند وجوده، دون التنقل إلى صفحة أخرى. يصدّر حقول المنتجات وميديا العملاء المسموح بها فقط مع إحصاءات التشخيص، ولا يقرأ حقول الحساب أو النماذج. لا صلاحيات جديدة.

تحسين الاسم عبر Gemini اختياري بمفتاح على السيرفر فقط؛ بدونه تستخدم الترجمة الحالية. صورة مصغرة حتى 320 بكسل تُرسل إلى السيرفر ثم Gemini عند تفعيله ولا يخزنها التطبيق. لا يتم تفعيل اشتراك أو فوترة تلقائيًا.

فك الحزمة في فولدر ثابت، وعطّل النسخة السابقة ثم Load unpacked واختر الفولدر. تحقق أن الإصدار 1.3.1 ثم حدّث صفحة الموقع. لا تُثبّت الإضافة آليًا. هذه نسخة فرع اختبار؛ يجب ربط الواجهة والباك والإضافة المطابقة قبل اعتمادها.
