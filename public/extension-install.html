الجلب المجاني من جهازك

الإصدار 1.3.0 يفتح تبويب عمل ظاهر في Chrome للبحث وقراءة أقسام المنتجات وريفيوهات العملاء العامة. لا توجد طلبات fetch خفية لصفحات أمازون. Chrome يستخدم جلسته العادية؛ الإضافة لا تقرأ كلمات السر أو الكوكيز أو بيانات الحساب، ولا تحفظ الميديا.

  1. نزّل الإضافة وفك ضغط الملف في فولدر ثابت.
  2. في Chrome أو Edge على الكمبيوتر افتح chrome://extensions (في Edge: edge://extensions).
  3. فعّل Developer mode، ثم Load unpacked، واختَر فولدر الإضافة الذي يحتوي manifest.json.
  4. راجع الصلاحيات: القراءة من متاجر أمازون الأربعة، والاتصال بموقع Creative Radaar فقط ونسخته المحلية للتطوير.
  5. افتح الموقع أو أعد تحميله وسجّل بكودك. اختَر فيديوهات أو صورًا أو الاثنين وحدد الأعداد، ثم ابحث باسم المنتج. رابط تنزيل الإضافة يختفي تلقائيًا بعد الاتصال بها.

النتائج تظهر بالتتابع وتختفي بتغيير المنتج أو تحديث الصفحة. حتى 50 فيديو و50 صورة حسب اختيارك والمتاح. البحث يكمل حتى 5 صفحات إذا احتاج؛ لا يمكن ضمان العدد لكل منتج. لتحديث الإضافة، عطّل النسخة القديمة وحمّل فولدر 1.3.0 باستخدام Load unpacked، ثم اضغط Reload في صفحة إضافات Chrome وأعد تحميل صفحة أمازون والموقع. عند خطأ 503 افتح المنتج يدويًا، ثم ارجع للموقع واختر «عرض صفحات منتجات أمازون المفتوحة» لقراءة ريفيوهات الصفحة التي اخترتها. لو أمازون طلب تحققًا بشريًا أو تسجيل دخول، الإضافة تتوقف وتوضح السبب. الإضافة تتطلب كمبيوتر؛ متصفحات الهاتف المعتادة لا تدعمها.
