الإضافة المجانية 1.3.1

البحث باسم المنتج وصورته لا يفتح تبويبات أمازون. النتائج مؤقتة وتختفي عند تغيير المنتج أو تحديث الصفحة.

  1. نزّل الإضافة وفك الملف في فولدر ثابت.
  2. افتح chrome://extensions، فعّل Developer mode، وعطّل النسخة السابقة.
  3. اضغط Load unpacked واختر الفولدر الذي يحتوي manifest.json. تأكد أن الإصدار 1.3.1.
  4. حدّث صفحة الموقع وسجّل بكودك. اكتب اسم المنتج، وأضف صورته، وحدد النوع والعدد ثم ابحث.

تحتاج الإضافة Chrome على الكمبيوتر. إذا رفض أمازون الجلب المباشر أو لم تتوفر فيديوهات عملاء، تظهر رسالة بالسبب. لا يمكن ضمان العدد لكل منتج. الصور والفيديوهات من ريفيوهات العملاء فقط.
