الجلب المجاني من جهازك

الإضافة تقرأ صفحات البحث والمنتجات العامة في أمازون عبر اتصالك. لا تستخدم حساب أمازون أو كوكيز تسجيل الدخول، ولا تحفظ النتائج أو ترفع صفحات أمازون للسيرفر.

  1. نزّل الإضافة وفك ضغط الملف في فولدر ثابت.
  2. في Chrome أو Edge على الكمبيوتر افتح chrome://extensions (في Edge: edge://extensions).
  3. فعّل Developer mode، ثم Load unpacked، واختَر فولدر الإضافة الذي يحتوي manifest.json.
  4. راجع الصلاحيات: القراءة من متاجر أمازون الأربعة، والاتصال بموقع Creative Radaar فقط ونسخته المحلية للتطوير.
  5. افتح الموقع أو أعد تحميله وسجّل بكودك. اختَر فيديوهات أو صورًا أو الاثنين وحدد الأعداد، ثم ابحث باسم المنتج. رابط تنزيل الإضافة يختفي تلقائيًا بعد الاتصال بها.

النتائج تظهر بالتتابع وتختفي بتغيير المنتج أو تحديث الصفحة. حتى 50 فيديو و50 صورة حسب اختيارك والمتاح. البحث يكمل حتى 5 صفحات إذا احتاج؛ لا يمكن ضمان العدد لكل منتج. لتحديث الإضافة لاحقًا، فك النسخة الجديدة في نفس الفولدر ثم اضغط Reload في صفحة إضافات Chrome وأعد تحميل الموقع. لو أمازون طلب تحققًا بشريًا أو تسجيل دخول، الإضافة تتوقف وتوضح السبب. الإضافة تتطلب كمبيوتر؛ متصفحات الهاتف المعتادة لا تدعمها.
